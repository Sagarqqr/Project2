# Developer Portfolio Project

A responsive, single-page developer portfolio website designed to showcase personal projects, technical skills, and colleague recommendations.

## 📌 Project Details
* **Project Name:** Developer Portfolio
* **Author:** [Your Name]
* **Role:** Full Stack Software Developer

---

## 🛠️ Tech Stack
* **HTML5:** Semantic layout structure
* **CSS3:** Custom styles, Flexbox, CSS Grid, and interactive hover animations
* **JavaScript (ES6+):** DOM manipulation, dynamic content rendering, and modal popups
* **Font Awesome:** Navigation and UI icons

---

## ✨ Features
* **Fixed Navigation Bar:** Quick navigation between sections (`#about`, `#skills`, `#projects`, `#recommendations`) with a working Home icon.
* **Profile Overview:** "About Me" section featuring a personal introduction and profile photo.
* **Skills Cards:** Interactive badges featuring core technical skills with logos.
* **Project Showcase:** Highlights key development projects with descriptions.
* **Interactive Recommendations:** 
  * Displays existing professional recommendations.
  * Interactive form allowing users to submit new recommendations dynamically to the page without reloading.
* **Confirmation Modal:** Triggers a popup notification (`showPopup`) upon successful form submission.
